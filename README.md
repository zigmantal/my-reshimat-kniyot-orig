# רשימת קניות - Reshimat Kniyot 🛒

A fast, clean, and intuitive grocery shopping list web application designed for Israeli & international supermarket shoppers. Built with React 19, TypeScript, and Tailwind CSS.

![Reshimat Kniyot](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/shopping-cart.svg)

## ✨ Features

- **🇮🇱 Bilingual & Full RTL Support**: Seamless Hebrew (עברית) and English interfaces with instant language switching and proper RTL layout direction.
- **⚡ Smart Auto-Categorization**: Automatically categorizes items into supermarket aisles (פירות וירקות, מוצרי חלב ומקרר, מאפייה, בשר ודגים, מזווה, ניקיון ופארם) as you type in Hebrew or English.
- **👆 One-Tap Quick Add**: Instant quick-tap chips for Israeli household staples (חלב 3%, ביצים L, קוטג', לחם פרוס, עגבניות, מלפפונים, שמן זית, נייר טואלט...).
- **📲 WhatsApp List Sharing**: Generates an aisle-grouped, emoji-formatted WhatsApp message ready to send to family members, partners, or roommates in a single tap.
- **📋 Starter List Templates**: Pre-configured shopping lists for:
  - Weekly Staples (קניות שבועיות)
  - Israeli BBQ / Cookout (על האש / מנגל)
  - Shabbat & Weekend Dinner (סעודת שבת)
- **💾 Offline & Local Storage**: Automatically saves your active and checked items locally on your device with no backend required.
- **🎯 Quantity & Unit Controls**: Fast +/- adjustments with units (יח', ק"ג, גרם, חב', בקבוק, קופסה).
- **🔍 Instant Filter & Search**: Search by item name, notes, or category, and filter between All, To Buy, and In Cart.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/reshimat-kniyot.git

# Navigate into the project folder
cd reshimat-kniyot

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Typography**: Google Fonts (Rubik)
